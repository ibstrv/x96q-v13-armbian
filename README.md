# X96Q LPDDR3 v1.3 — диагностическая сборка Armbian

Первый образ предназначен только для проверки стабильной загрузки и Ethernet.
Проблемный драйвер `xradio_wlan` намеренно заблокирован, поскольку предыдущий
образ падал внутри этого драйвера во время обработки прерывания.

## Как запустить сборку

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки, включая каталоги `.github` и
   `userpatches`.
3. Откройте вкладку **Actions**.
4. Выберите **Build X96Q v1.3 diagnostic image**.
5. Нажмите **Run workflow**.
6. После завершения скачайте файл `.img.xz` из созданного Release.

Дополнительные секреты создавать не требуется: используется штатный
`GITHUB_TOKEN` репозитория. Workflow нужны права на запись содержимого, чтобы
опубликовать собранный образ в Releases.

## Правила первого теста

- Загружать только с microSD.
- Не запускать установку на eMMC.
- Подключить HDMI и Ethernet.
- Сначала выполнить три обычные перезагрузки.
- Затем выполнить три холодных запуска с отключением питания на 15 секунд.
- После каждого запуска записывать результат и время до появления приглашения.

## Что проверить после входа

```bash
uname -a
cat /proc/device-tree/model; echo
ip -br addr
ethtool end0 2>/dev/null | grep -E 'Speed|Duplex|Link detected'
journalctl -b -p err..alert --no-pager
dmesg | grep -iE 'panic|oops|mmc3|xradio|wlan|gmac|ethernet'
```

Если шесть запусков проходят без сбоя, следующий этап — отдельный Wi-Fi-билд с
точным DTB и проверенным вариантом драйвера XR819/XRadio.
